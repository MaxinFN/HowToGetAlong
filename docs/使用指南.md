# 遇到事情时怎么查

这份指南帮助你选择动作，不替你保证别人满意。先确认事实、双方关系、已经作出的承诺，再比较可接受的代价。

## 根据情境检查六件事

日常小事只检查会改变选择的部分，不必每次都完整填写。

1. **目标**：我希望完成什么？双方是否有可兼顾的目标？
2. **信息**：哪些事实已确认，哪些只是猜测？只核实必要信息，不窥探隐私。
3. **条件**：职责、已有承诺、权力关系、场合与时间，会怎样改变选择？
4. **办法**：可以直接做、协商、换渠道或退出吗？各自花掉什么、可能换回什么？
5. **准备**：采取行动前，需要哪些材料、资源、确认或替代安排？小事不必增加审批。
6. **进退**：出现什么可观察的反馈时，需要继续、调整、暂停或求助？

这些问题受《孙子兵法》的判断思路启发，是本项目用于日常相处的转译，不能保证效果。古文出处和转译边界见[学习笔记](孙子兵法学习笔记.md)。

每条先读“判断关键”，再看“行动前准备”和“先做什么”，选择适合条件的表达。跟进时看“何时换办法”，不必坚持使用已失效的话术。

## 复制、收藏与分享

条目下方可以“复制示例”“收藏”“分享”，也可以反馈当前条目。复制的是“可以怎么说”，保留简短免责声明；接续对话需要结合整段情境阅读，不把对方的可能回应当作事实。

收藏保存在当前浏览器，勾选“只看收藏”即可筛选；取消收藏只影响该条，清除筛选不会删除收藏。收藏不会上传或自动跨设备同步。浏览器禁止保存时会提示只能暂存；清除浏览器数据或使用不同文件、浏览器时，收藏可能无法保留。

分享会调用浏览器分享功能，或复制公开在线条目的链接，不包含收藏和本地文件路径。自动复制受限时会打开手动复制窗口。来源编号可点开原始来源，外部来源与反馈需要联网；单个 HTML 离线支持正文检索，完整配套页仍需项目 ZIP。

## 阅读接续对话

借钱、临时加活、劝酒、隐私追问、接夸、代签到、八卦站队和关系施压的条目中，展开细节可查看接续对话：第一次表达、可能回应、继续回应与调整信号。均为编写情境，不能保证事情如此发展；涉及已有承诺时先处理相应责任。

## 一次只选一个能落实的改变

先明确一件事，例如确认期限、说明不外借、询问对方需要倾听还是建议。不必一次套用整本书，也不必把每次普通聊天都变成谈判。

表达后看实际结果：对方是否理解？约定有没有变化？问题是否反复？根据结果继续协商、换渠道或减少参与，而不是只评价自己这句话够不够“高情商”。

## 哪些情况需要其他办法

遇到人身威胁、严重伤害或紧急危险时，先求助适合所在地的紧急或专业渠道，不把独自沟通当成必须步骤。具体法律、健康、财务及正式纪律问题不靠话术判断；本版提供交往方向，不能替代这些领域的处理规则。


## 读完以后怎么练

如果找不到场景、看不懂下一步或觉得表达不自然，欢迎通过[读者反馈与案例征集](读者反馈与案例征集.md)提供具体意见。无需真的试用，也不要提交个人身份信息。

选一次真实交流或即将遇到的场景，用[交流复盘与场景练习](交流复盘与场景练习.md)写下事实、已表达的需求、行动与反馈。每次只选一个可执行调整，不把猜测当作事实，也不把相处变成回报记账。组织聚餐看 7.8，来访接待看 7.9，具体夸赞看 7.7。
