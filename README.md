# 人情世故指南

**一份面向大学生和初入职场者的相处指南：讲清怎么做、怎么说，以及可能付出什么代价。**

帮助大学生和初入职场的人处理合作、求助、拒绝、金钱、礼节和冲突。每条写清判断关键、行动前准备、动作、示例表达、成本、可能效果、调整信号和例外。你可以挑一条试用，也可以根据自己的关系和环境调整。

## 怎么读

- 打开 [阅读与检索页](index.html)，按关键词、场景和主题查找。页面支持离线使用，不需要登录。
- 在 GitHub 上阅读时，可直接查看下面的分章正文。使用 HTML 页面时，点击仓库的 **Code → Download ZIP**，解压后用浏览器打开 `index.html` 或 `阅读全文.html`。
- 打开 [连续阅读版](阅读全文.html)，从头阅读全部章节，并可用浏览器打印或保存为 PDF。
- 下载 [完整文字版](完整指南.md)，离线阅读或继续编辑。
- 不知道从哪里开始，先看 [使用指南](docs/使用指南.md)。
- 喜欢纯文字，可以按下面的问题读 `book/` 正文。
- 每条的“可以怎么说”都是本项目拟写的示例，不是平台原话，也不保证对方接受。
- 展开“准备、不同情境与调整信号”，区分普通朋友、亲近关系、职责内请求等条件，别只照搬一句话。
- 本版没有经过系统访谈、行为测试或逐条研究验证。平台调研提供选题线索，不证明方法有效。涉及学校、单位和法律的具体要求，需要另查对应规则。

## v1.1 的判断与行动框架

从《孙子兵法》的权衡、行动前准备、组织协作与因情境调整中提取编辑思路：先问目标和条件，再准备、行动，并根据可观察的反馈换办法。60 条均已补充具体问题、准备事项与调整信号。

生活建议是本项目的转译与经验判断，古文不能证明其有效；不将朋友或同事默认当成敌人，也不采用欺骗、离间、制造退路困境或侵犯隐私的方法。详见[学习笔记](docs/孙子兵法学习笔记.md)与[v1.1 融合记录](docs/核实记录/v1.1说明.md)。

## 如何理解依据

不把经验、制度和研究放在一把尺子上打分，也不计算“情商分”或社交成功率。

| 类型 | 要求 | 本版情况 |
|---|---|---|
| 研究支持 | 原始研究来源、研究对象、主要结论与局限 | 暂无 |
| 制度规定 | 官方文本、适用地区或机构、截至日期 | 暂无具体制度结论 |
| 经验建议 | 标明为可选办法，列出代价、例外与失效可能 | 63 条 |

“可能换回什么”是编辑预期，不是已测得的效果。“花掉什么”包含时间、金钱、压力与关系代价。同一句话面对室友、老师、朋友或领导，效果可能不同。

## 给 AI 使用

配套 [social-situations-guide](skills/social-situations-guide/SKILL.md) 已包含一份正文快照。使用它回答具体场景时，先查条目，再注明章节与依据类型；查不到就说明缺项。

例如：“用这份指南帮我处理：同学总让我改 PPT，我不想继续接。”本项目里的 Skill 尚未安装到你的全局技能目录。

## 编辑与生成

正文在 `book/`，每条的标签用于页面筛选。修改正文后运行：

```bash
python3 tools/build.py
```

脚本会检查条目字段、连续编号和交叉引用，生成无需联网的 `index.html`、`阅读全文.html`、`完整指南.md`，同步 Skill 的正文快照。只依赖 Python 标准库。版本与定位在 `project.json` 中维护。
